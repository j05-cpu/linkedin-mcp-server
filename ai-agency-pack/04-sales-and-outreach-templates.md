# 💼 Sales, Outreach & Client Onboarding Toolkit

Tech-aware clients ke saath deal execute karne ke liye sabse imp point hai: **Zero fluff, 100% direct value & proof**. Below are high-converting outreach scripts in both English and Hinglish, proposal structure, pricing, and onboarding checklist.

---

## 1. Cold DM Scripts (For Tech Founders & Agency Owners)

### Option A: Hinglish / Informal Direct Approach
> **Subject / Hook**: Saw your post about AI workflow automations / Quick question about your content flow
>
> *"Hey [Name], loved your recent post on [Topic/AI Tech]. Saw that you guys are scaling fast!*
>
> *Quick context: Main micro-automations build karta hoon specifically for tech founders. Maine ek automated workflow banaya hai jo Gemini Imagen + LinkedIn API ko hook karke automatically custom visuals generate karke posts schedule kar deta hai without buffer/hootsuite.*
>
> *Maine iska 45-sec demo loom video banaya hai. Direct link share karun aapke saath?"*

### Option B: English Tech-Focused Approach
> *"Hey [Name], noticed you're heavily leveraging AI tools for [Company Name].*
>
> *I build lightweight, custom micro-automations (like auto-generating custom AI visuals for scheduled posts & automated competitor tracking via background daemons).*
>
> *No clunky SaaS tools or high monthly subscription fees—just a custom lightweight script deployed on free infrastructure.*
>
> *Mind if I send over a 1-minute video demo of how it works?"*

## 2. 1-Page Proposal Template (`proposal-template.md`)

```markdown
# 📄 Micro-Automation Setup Proposal

**Client**: [Client Name / Company]
**Prepared By**: [Your Name / Agency Name]
**Date**: [Date]

---

### 🎯 Objective
Automate [Specific Task, e.g., LinkedIn content scheduling & image generation] to eliminate manual copy-pasting and save 5+ hours per week.

### ⚙️ Scope of Work & Deliverables
1. **Custom Automation Setup**:
   - Integration of Google Gemini Free API for AI image & content drafting.
   - Configuration of background scheduler / cron daemon.
2. **Telegram / Email Notification Alert**:
   - Instant real-time alerts whenever a post is published or if any API error occurs.
3. **Documentation & Handover**:
   - 5-minute video walkthrough & setup guide.

### ⏱️ Timeline & Turnaround
- **Delivery Time**: 48 hours from API credentials handover.

### 💳 Investment
- **One-Time Setup Fee**: $200 (₹16,000 INR)
- **Monthly Maintenance (Optional)**: $50/mo (Includes model prompt tuning & server health checks)
```

## 3. Client Onboarding & API Credentials Checklist

Jab client deal close kar le, to unse sirf ye items request karein:

- [ ] **Google Gemini Free API Key** (Or guide them via a 1-min Loom video on how to get it from Google AI Studio).
- [ ] **LinkedIn App Credentials / OAuth Access** (Client ID & Client Secret) or platform credentials for the specific micro-automation.
- [ ] **Telegram Bot Token & Chat ID** (if automated alert notifications are enabled).
- [ ] **Target Brand Voice & Niche Guidelines**.

## 4. Payment Terms & Handling

- **50% Advance / 50% Post Delivery** (Initial clients for trust building).
- **Payment Modes**:
  - India: UPI, Razorpay, Bank Transfer.
  - International: Stripe invoice, Wise, PayPal, Payoneer.
